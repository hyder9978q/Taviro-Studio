# Taviro Studio

An automated, faceless content studio focused on discovering, researching, producing, publishing, and learning from digital content.

## Core pipeline

Research → Evidence → Idea → Script → Production → QA → Publishing → Analytics → Learning

## Principles

- Automation-first from day one.
- Evidence and original testing over generic AI-generated filler.
- Modular architecture so tools and models can be replaced.
- Free-first infrastructure during validation.
- Measure content performance and operating cost.
- Publishing adapters remain replaceable; AutoSocial is treated as a distribution component, not the core business logic.

## Initial stack

- n8n — orchestration
- Local AI/tools — research and generation where practical
- FFmpeg — media processing
- AutoSocial — local publishing adapter
- GitHub — source control and project documentation
